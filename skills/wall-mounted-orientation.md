# 牆面物件方向自檢

| 項目 | 內容 |
| :--- | :--- |
| 版本 | 1.0 |
| 最後確認 | 2026-11-21 |
| 適用 | 需求方等角場景的牆面素材，及需要區分貼牆與地面擺放的單件／逐格動畫 |
| 不適用 | 透視鏡頭、其他投影或需求單另定角度的素材；不能用此表替需求方決定掛哪面牆 |

## 牆面對照

| 類型 | 畫面位置與朝向 | 水平邊的走向 | 需求方已核准的對照物 |
| :--- | :--- | :--- | :--- |
| 西牆 | 畫面左側，牆面朝右下 | 往右上升，2 右／1 上；左低右高 | agent-office 舊門 `web/public/sprites/office/door.png` |
| 北牆 | 畫面右側，牆面朝左下 | 往右下降，2 右／1 下；左高右低 | agent-office 的 `kanban-board`、第四批 `clock` |
| 地面物件 | 不貼牆，依場景地面與需求單擺放 | 依需求方已核准的地面物件檢查兩組地面軸向，不套用單一牆面斜向 | 需求單指定的已核准地面物件 |

等角投影沒有近大遠小：同方向的邊互相平行，左右兩側的垂直高度相同，不向消失點收斂。門框、門檻、出口燈及物件內部的同面細節，都要隨同一面牆的方向，不能只改外框。

## 開工前與提示詞

1. 從需求單逐件確認西牆、北牆或地面，並找出需求方已核准的同牆對照物與建議顯示格數。單上沒寫牆面、描述不清楚或沒有可確認的對照物時，先在該單提問並用 `task wait <N> --worker <代號>` 等回覆，不自行猜牆面。
2. 使用[agent-office 範本 1.2](../prompts/agent-office.md)的方向替換段，每件只選對應的一段；不沿用其他物件的 `facing bottom-left`、西牆或北牆字樣。參考圖註明是方向、畫風或物件身份參考。
3. 動畫沿用同一牆面、母圖畫布及靜態物件位置，只變指定的活動部分。生成結果仍須檢查，不因提示詞寫對就視為成品方向正確。

## 交件前自我檢查

1. 每件與需求方**已核准**的同牆對照物放進同一張預覽圖，依建議顯示格數用同尺度縮放，不把每件獨立拉到同高掩蓋比例差異；標明代碼、牆面與對照物。原圖與去背成品不縮放。
2. 並排確認上下水平邊的斜向一致，檢查左右垂直邊等高且平行，以及內部面板、門上標誌等同面部件。西牆左低右高，北牆左高右低；若方向不一致先重畫，不能只修改表格。
3. 核對交件表的牆面欄、實際提示詞與成品方向三者一致，清楚記錄相對舊版改了哪面牆。
4. 方向檢查預覽跟成品一起交到需求方指定位置，交件留言附該圖連結。牆面動畫同時附共同座標的逐格 GIF，依[原圖去背流程](gpt-original-cutout.md)檢查定位及如實揭露生成微差；人工看圖仍由需求方確認。
